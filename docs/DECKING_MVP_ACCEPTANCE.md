# Decking MVP Acceptance

## Purpose

This document defines the finish line for the Decking workflow before building or modifying application behavior.

## Acceptance Transcript

```text
Quote for Susan at 6 Tarawera Terrace.

Deck measures 12.8m by 15.6m.

Remove existing deck.

Estimate 2 people for 2 days for removal.

Use Kwila 140x19 for the entire deck.

Use decking template.

Posts are still in good condition and will remain.

Allow time for tidy up.

Entire project should take approximately 2 weeks with 2 people.

No staining.

Access is poor, allow an additional 10 hours.
```
