# Talk to Quote Project Overview

## Purpose

Talk to Quote is an AI-powered voice-to-quote application that helps trade businesses turn spoken site notes into structured quote drafts.

## Core Workflow

1. Record or paste job notes.
2. Transcribe and correct trade-specific language.
3. Extract quote details with AI.
4. Match templates, knowledge base items, and pricing libraries.
5. Review, edit, and save quote drafts.

## Primary Users

- Gardeners and property maintenance businesses
- Landscapers
- Builders
- Electricians
- Plumbers
- Painters
- Cleaners
- Arborists

## Key Modules

- Supabase authentication and user profiles
- Voice recording and transcription
- AI quote extraction
- Quote review and draft saving
- Knowledge Base
- Templates
- JMS Item Library
- Plant Library and planting calculator
- Testing / Debug runner

## Current Status

Initial product build with working authentication, transcription, extraction, draft saving, template learning, knowledge imports, and debug testing tools.
